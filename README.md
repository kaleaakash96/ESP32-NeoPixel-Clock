
# Effect mode Settings commands 
    Commands                           Effect & color
      0.                              Default Effect 
      1.                              Red fadding effect
      2.                              Green fadding effect
      3.                              Blue fadding effect      
      4.                              Cyan fadding effect
      5.                              Coral fadding effect    
      6.                              gold fadding effect
      7.                              Orange fadding effect
      8.                              Red solid
      9.                              Green solid  
      A.                              Blue solid
      B.                              Cyan solid
      C.                              Coral solid  
      D.                              gold solid
      E.                              orange solid
      F.                              Rainbow effect  


# Set Time on Clock 
  "GHHMMG" == G = start Command , HH = Set time Hours , MM = Set time Minuts , T = End command.

# Set Clock Digit Color 
  "IXI"  === I = Start command , X = 1 - 7 Color code as below mention , G = End Command.
  
    1. Red solid
    2. Green
    3. Blue
    4. Cyan
    5. Coral
    6. gold
    7. Orange

# Check Current Set time 
  Command = "H".
